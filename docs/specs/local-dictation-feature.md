# Offline live decoder and single microphone capture

Kind: feature

## Purpose and scope

“It must be able to show text while you’re still speaking.” Replace SDL/terminal-output dictation, not clip mode, with one Micme-owned local whisper.cpp process and one stateful Silero detector per live recording. Use one recording as the source for live inference, meter, stop and optional final pass. No service, extra Pi command, GPU requirement or second microphone.

## Behaviour today

| Entry point | What it does today | File and symbol |
| --- | --- | --- |
| Toggle | Stream starts `whisper-stream` and optionally an independent recorder; clip uses the configured recorder only. | `src/extension.ts:startStreamingTranscription`, `startClipRecording` |
| Decode/deliver | CR/LF frames become word candidates, then editor text on overlap, mismatch, timer or stop; optional final clip can replace it. | `src/streaming.ts:extractStreamingCandidate`, `scheduleStreamingFlush`; `src/extension.ts:completeStreamingStop` |
| Resolve | Auto/C++ stream uses the stream binary; clip may instead use custom/Python. C++ resolution includes explicit path, model cache, translation mapping and cancellable downloads. | `src/backends.ts:resolveTranscriptionPlan`; `src/models.ts:resolveWhisperCppModel`, `ensureWhisperCppModel` |
| Configure | Mode selection writes multiple timing/context/threshold defaults and final-pass flags. | `src/config.ts:getTranscriptionModeProfile`; `src/settings.ts:buildConfigurationItems` |

## Target behaviour

| Rule | Trigger | Result | Limits |
| --- | --- | --- | --- |
| Provision | Explicit initial setup | Build a standalone C++17 `micme-live` against whisper.cpp v1.9.6 at the revision in the research note. Supply buildable sources in the npm package and one documented local build/install entry point; use an installed/pinned local source tree or fetch the exact revision during explicit setup. | No npm install hook, runtime compilation, vendored weights or unpinned binary download. No Pi provider login. Offline after provisioning. |
| Start | Toggle stream | Validate config, resolve both weights and executable; start owned worker; require v1 ready. Start one recorder and report listening only on actual PCM. Tell the speaker when ready, not while fetching/loading. | Bound model load/first PCM/final waits by configured transcription timeout; cancellation supersedes all waits. |
| Capture | FFmpeg device chosen or explicit recorder hook | Built-in stream writes a growing mono 16 kHz LE16 WAV, packets flushed promptly; retain OS selector/timing sync. Apply configured audio filter once when preprocessing enabled. Custom hook must write that decoder-ready format to `{audio}`. It alone owns any filtering of its stream; Micme does not apply the user's filter to hook output. No clip preprocessing of *either* spool during refinement. | No second input or meter branch. Clip sample-rate/meter controls do not change the worker format. Keep a held, verified regular-file descriptor and use recording-directory access, never the display path for I/O. |
| Feed | WAV grows, decoder consumes | Parse RIFF/WAVE chunks, padding, actual data offset and placeholder lengths while growing; use file size, complete samples, monotonic cursor. The spool is append-only PCM in the same regular file; only RIFF/data size finalization in its header is permitted. Read via the verified leaf handle, meter those samples, and drain that handle through stop. A pathname/size match is not file or content identity. | Reject truncation, incompatible format or unsupported RIFF size, stalled startup, malformed final length. Do not assume a 44-byte header or treat metadata as speech. No per-window audio files. |
| Verified leaf | Opening the growing spool | POSIX: inspect the descriptor from the owned no-follow open. Windows: retain ancestor locks; inspect and read the same `CreateFileW` leaf handle opened with `FILE_FLAG_OPEN_REPARSE_POINT`. Accept a disk file, not a reparse point or directory. | `src/recording-dir.ts:RecordingDirectory.openFile` today falls back to a path open on Windows; POSIX `O_NOFOLLOW` is not a Windows guarantee. If safe handle access cannot be established, refuse stream capture, never retry with an ordinary path open. |
| Refinement input identity | Clean stop with acknowledged speech and final pass enabled | Give the path-based clip transcriber a private WAV copied from the verified held leaf, never the hook's pathname. Use the Capture contract's payload digest and count check. | A replacement at stop may have the same name, format and length but different PCM. Refine only from the verified original, otherwise warn without replacement/send. Remove the private copy on success, failure and cancellation. |
| Gate | New contiguous PCM | Carry Silero state across correctly sized frames; use speech probabilities, not a success boolean. Start at ≥0.5 for ~64 ms, release below 0.35 for 500 ms, retain 250 ms onset padding and ~200 ms tail. Pad only last incomplete detector frame; never count padding as captured samples. | Starting operating points, validate quiet/short speech with native corpus. A peak/volume threshold is not a speech classifier; no unconditional text blacklist. |
| Preview | Open speech continues without pause | First preview decode after ~1 s of voiced input (sooner on endpoint), then on ≥1 s additional audio while caught up. Greedy/no temperature retries, no speculative prompt carry. Publish latest complete hypothesis for the uncommitted span. Recognize explicit language; for auto + multilingual, detect on accumulated voiced input once, reuse that language. | One loaded ASR context and VAD context, one serial decode; skip obsolete *previews* while draining a backlog, never skip gate samples or endpoint work. Don't decode during silence. |
| Close a span | Speech endpoint, long utterance or finish | Re-decode remaining voiced span and finalize once. For continuous speech, bound ASR context to ≤28 s; by ~20 s cut at a decoded token/segment boundary, retain ~1 s context around cut, map timestamps to absolute samples and assign by midpoint to one half-open interval. Restart preview on uncommitted audio. If the gate stays open but an entire 20 s of unfinalized input yields no words/boundary, emit an **empty final** through exactly span start + 320,000 samples. Discard that prefix including its overlap, keep later samples and the continuous VAD state, then start a fresh draft at the new frontier. Do this also during catch-up; never wait beyond the window cap. If there is text but no usable monotone timestamp to partition it at the cap, fail explicitly instead of assigning words invented times. | No word-string dedup across distinct times; repetitions remain valid. Never finalize a guess merely because text stopped arriving. Stop drains through the final sample. |
| Deliver | Partial, final, finish | Display partials only in the widget. In TUI append finalized spans once to the observed editor under the existing edit guard. In write-only RPC keep finals in the operation only: no automatic editor replacement, paste or send, even if auto-submit is on. Remember the completed transcript. Optional clip refinement uses a private verified copy of the acknowledged PCM from the held leaf (Capture contract); skip it for no speech. | Never submit on partial, cancellation, invalid completion or final-pass failure. Do not preprocess a stream capture twice. Existing clip final-backend selection is explicit opt-in via the final-pass setting. |

## Failure cases

| Input or state | What the user or caller gets back |
| --- | --- |
| Worker/VAD/ASR missing, wrong version, incompatible model/language or failed load | Before listening: report the component and how to set it up, select the proper model or choose clip. No fallback to SDL/clip, empty-success startup, or external inference. With download disabled, make no network attempt. A worker exit or malformed ready is failure even with code 0. |
| Recorder never provides valid PCM, device denied or recorder exits | Stop both owned processes, clear view, explain required device or custom-hook format; preserve usable partial audio under existing failure policy, report path. Save only words already confirmed, as for worker errors. |
| Worker error, invalid UTF-8/JSON, out-of-order final, count mismatch, oversized line, timeout or unexpected exit | Discard draft and stop work; surface one sanitized, bounded error. Preserve already committed editor text and failure audio; save confirmed words for `/micme last` or leave the previous transcript if none were confirmed. Never claim complete dictation or auto-submit it. |
| Successful capture with no speech | No words, paste or submission; clear draft/status, give normal no-words warning. Optional final does not run. Clip-only silence behavior unchanged. |
| Final clip refinement fails or user has inserted text | On failed refinement keep confirmed live transcript available via `/micme last`, keep audio according to existing failure rules and warn, never send. In TUI retain the existing guard for observable additions. In RPC never infer the host prompt from an empty read or cached Micme writes; give explicit replay instructions (Compatibility). A mismatched/unverifiable snapshot is a refinement failure before replacement or submission. |
| Session closed while downloading, loading, capturing or draining | Operation abort cancels file polling, transport/finalization, timers and children using existing owner/tree cleanup. No late status, editor, widget, submit or download callback; close descriptors only once users of them finish. |

## Data

| Field | Type | Default | Stored in |
| --- | --- | --- | --- |
| `MICME_LIVE_BIN` | optional path or executable name | Resolve `micme-live` on PATH | Environment over existing `micme.json`; never resolve the SDL binary as a worker. |
| `MICME_VAD_MODEL` | optional local file path | `vad/ggml-silero-v5.1.2.bin` under effective C++ model cache | Same precedence. A missing explicit custom path fails. For the standard file use the matching official ggml-org/whisper-vad artifact pinned by revision and checked digest. Apply auto-download opt-out, atomic transfer, inactivity bounds, shared cancellation, regular-file checks. Do not list VAD as ASR weights. |
| Effective ASR model, language and translation | Existing C++ path and language code / flag | Existing C++ resolution (`small.en`, English absent override) | Existing settings in `src/models.ts:resolveWhisperCppModel` and `src/config.ts:getTranslateToEnglishLanguage`. Preserve translation-aware model mappings/warnings; reject known incompatible live combinations before recording rather than silently returning English. |
| Live cursor, draft, confirmed ranges, timings | operation-local state | zero / empty | Memory; audio in owned `raw.wav`. No telemetry or transcript logging by default. Opt-in diagnostics may show durations, counts, sample lag, effective component names; sanitize external strings. |
| Keep audio, final pass, auto-submit | existing flags | existing false defaults when unset | Existing config; see mode switch behavior under Compatibility. Do not keep additional files merely to measure performance. |

## Compatibility

| Caller, stored data or setting | How the change affects it | What happens to it |
| --- | --- | --- |
| Clip / Python / custom transcriber | Keep behavior and setup as is; selecting stream still requires auto or whisper.cpp. | No automatic backend/model downgrade. Explicit optional final refinement retains existing clip backend resolution. |
| Old `MICME_WHISPER_STREAM_BIN`, `MICME_STREAM_CAPTURE`, `STEP_MS`, `LENGTH_MS`, `KEEP_MS`, `MAX_TOKENS`, `KEEP_CONTEXT`, `WORDS_PER_CHUNK`, `FLUSH_MS`, `VAD_THRESHOLD` (timing names prefixed `MICME_STREAM_`) | Belong to the retired SDL path. Never reinterpret old threshold/indices/units as Silero or OS inputs. | Mark deprecated/ignored in schema/help; remove from example and picker. Leave stored keys intact. If set, one concise stream migration advisory naming worker, Audio input and ignored settings; not once per frame/toggle. |
| `MICME_STREAM_FINALIZE_WITH_CLIP`, `MICME_STREAM_DIAGNOSTICS` | Remain effective switches. | A settings mode switch writes only the mode and the final-pass default (`0` for stream, `1` for clip). In stream mode, opt in after switching; shell overrides still take precedence. Final reads captured audio, diagnostics explain new events/timings. |
| Recorder hooks / capture overrides | Same OS inputs as clip (including macOS explicit input, Linux `MICME_PULSE_SOURCE`, exact Windows device name). A custom hook takes precedence and must expose growing PCM WAV while streaming. | Incompatible hook errors rather than silently switching microphone. Stream fixes worker-format rate; clarify filter/sync behavior. Built-in capture: with `MICME_PROCESS_AUDIO=1` apply configured nonempty filter once before spooling; with `0` apply none. Hook: output is authoritative regardless of this switch. A raw hook stays raw for live and final; an already-filtered hook keeps its one filter pass with no extra setting or inference. To filter a raw hook, include the filter in that hook or choose built-in capture. All refinement consumes decoder-ready PCM without re-filtering. |
| `/micme last`, `/micme audio`, `MICME_KEEP_AUDIO`, edited TUI and write-only RPC editor | TUI: append to actual editor text; an observed addition (including replay) prevents final replacement/auto-send. Preserve existing clear/trim semantics: clearing a Micme-written suffix alone does not latch an insertion. RPC: `createGuardedContext` knows only Micme's writes, not a host edit. Never write the editor or send automatically in live RPC, even with a cached replay or an apparently empty prompt. Clip-only behavior unchanged. | RPC finish: tell user transcript is saved and what explicit `/micme last` will do: replace the prompt with auto-submit off, send/queue with it on. The user can save their prompt or turn off auto-submit first. An explicit replay during recording remains a tracked user action; no later live/final event replays over it. |

## Decisions

| Decision | Chosen | Rejected | Why |
| --- | --- | --- | --- |
| Local interface | Private child with compact PCM input and structured events | Public/loopback API or native ABI loaded into Pi | No service to expose or native crash in Pi; process lifecycle already exists. |
| Stream implementation | Resident Whisper + real VAD, independent of SDL | Per-update whisper-cli, legacy terminal parsing, or pause-only CLI | User requires text *during* speech and accepts an extra local component. Repeated model loads undermine that requirement. |
| Durable vs tentative | Preview during speech, endpoint or bounded-range final after re-decode | Append-on-timeout and global word dedup | A word guess can change; repeated words at different times are legitimate. |
| Deployment | Opt-in source build/install plus explicit executable path | New binary publishing pipeline or mandatory install-time downloads | Honors current local tool model (`README.md`, Backend Setup); clip installs stay lightweight. |
