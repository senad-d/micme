To repeat, use the local Pi fixture launcher described in [the native replay guide](README.md), with an isolated config providing the pinned CLI, managed cache path and explicit sample instead of the scripted ASR. Leave `MICME_LIVE_BIN` unavailable, `MICME_AUTO_DOWNLOAD_MODEL=0`, and set `MICME_AUTO_SUBMIT=1` in the disposable fixture before launch. From `/micme setup`, open **Models and repair**, type `installed lang:en`, verify the selected pin and choose **Use for Whisper dictation**. Choose **Try It: local sample**, enter the sample path and select **Transcribe sample**. In a separate run choose **Try It: microphone**, select **Start recording**, then stop with the ordinary toggle. Repeat at both widths.
