All eight reviews contained the expected public speech; no editor write, send or queue was observed in the instrumented Pi receiver. Opening setup or its migration preview did not start the recorder or change saved config. Pressing Enter on the mic confirmation's default **Cancel** also did not start the recorder. Selecting **Start recording** did: setup returned, the opaque recorder ran without a readiness claim, and the usual toggle stopped it. The isolated custom hook copied the public WAV only on SIGINT and exited 255. ASR and Pi review were real, while mic input was a close-only fixture, not a physical device or permission test. Neither recorded audio nor the sample went to a provider or output hook.

To repeat, use the local Pi fixture launcher described in [the native replay guide](README.md), with an isolated config providing the pinned CLI, managed cache path and explicit sample instead of the scripted ASR. Leave `MICME_LIVE_BIN` unavailable, `MICME_AUTO_DOWNLOAD_MODEL=0`, and set `MICME_AUTO_SUBMIT=1` in the disposable fixture before launch. From `/micme setup`, open **Models and repair**, type `installed lang:en`, verify the selected pin and choose **Use for Whisper dictation**. Choose **Try It: local sample**, enter the sample path and select **Transcribe sample**. In a separate run choose **Try It: microphone**, select **Start recording**, then stop with the ordinary toggle. Repeat at both widths. A preseeded copy is offline provisioning, not an in-app CDN transfer.

## Catalog, repair and diagnostics

- **M2/L2:** The catalog showed 73 tagged Handy ASR rows alongside the managed Whisper models. `stream moonshine` matched reference claims with unknown measured languages and no offered load; `installed lang:en` matched the local Whisper file. Presence was labelled unchecked until verification. Language, streaming and translation are separate filters; unknown language claims do not become verified support. At 80 columns the language picker changed transcription language, then the separate translation picker set French → English without changing the saved English transcription setting. Try It rejected the explicit `tiny.en` translation choice before sample confirmation or recorder start. No native translation accuracy is claimed.
- **M3:** `test/transfer-setup.test.mjs` observed no request until explicit authorization and no model selection after a mismatched response. Opening Try It with missing or corrupt managed bytes did not reach the host. The managed-service tests separately check exact-byte publication, resume, cancellation, shared waiters, and refusal to delete unowned paths. The native journey exercised preseeded offline verification, not a live CDN, proxy or mirror.
- **A2:** Settings first showed Advanced controls as hidden. Revealing them did not write a setting or activate a provider, hook or recorder. Saved prompt/text canaries and a fake credential configured for the isolated run did not appear in the settings view or doctor output. The settings component tests exercised keyboard editing of a preferred-language list and focus return without prefilling the saved list. Optional compute/artifact/detector controls had no qualified installed context in this P3 run; activation of qualified native alternatives and downstream language/processing behavior need their own evidence.
- **Doctor:** Separate offline subprocesses reported **missing**, **corrupt** and **verified size and SHA-256** for managed weights. A protocol-only fixture was recognized as Worker v1; doctor still reported **capture readiness: not tested** and no actual device or channel. Config and the recorder trace were unchanged. The fixture does not prove a working live decoder or physical capture. Existing doctor tests cover independent no-Pi-peer startup and redacted processing options.

These are functional observations, not frozen B comparison takes. No `takes` or `before` references are fabricated: this run has no calibrated same-condition reference for a timing comparison. No browser UI is shipped; the visual evidence is the real Pi terminal at 40 and 80 columns.
